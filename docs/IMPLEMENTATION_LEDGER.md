## 第三批进度（尚未完成）

- C1：账号供应商、失效域和共享额度池由操作员确认，换源后自动失效；相同供应商/失效域/额度池/URL+凭据组成同一故障组件。停调保护按独立组件计数。原生并发接口没有成功状态时只显示上报余量，不认证容量。
- C2：模型价格卡区分输入、输出、缓存读写、币种、token 单位、换算、倍率和充值比例。只有同一分组流量结构与共同基础的成本才进入排序。余额续航要求同来源/同单位/足量时间跨度，充值、重置或剧烈波动后保持未知。用户售价未纳入自动写回。
- C3：真实请求与 usage 改为站点批量采集；合成请求带独立 request/session ID 并从用户结果和流量结构中排除。用户结果按站点代次、组和 request_id 去重，未知/冲突结果不算成功。通用任务租约有 UUID 拥有者、30 秒续租、丢失取消、同资源合并和 90 秒控制周期上限。新增自适应探测、不可行配置提示以及运行状态页面。
