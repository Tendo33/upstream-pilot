# 使用手册

## 接入

在站点页填写 Sub2API 根地址与管理 Key，同步账号和组。连接本机或可信内网时，才启用 `PILOT_ALLOW_PRIVATE_UPSTREAMS=true`。多租户公网实例不应随意开放内网访问。

在质量页选择实际支持的测试模型，设置探测间隔、超时和采购倍率采集。统计窗口与最新证据有效期分别设置；间隔应与所需样本量和模型的正常耗时匹配。

## 控制

- 观察模式记录建议，不发送自动参数修改。
- 自动优先级按组内顺序调整；数字较大表示较低优先级。
- 停调只在明确启用、确认硬故障并有有效健康备用时尝试。
- 并发上限和负载系数分别开启，按风险级别降低并恢复。
- 外部人工修改会触发冲突，避免自动覆盖。

“还原基准并停止”恢复受管理的优先级和容量。调度开关仍在账号页单独控制。“保留当前值并停止”解除接管并采用现值，不进行参数还原。待确认写回也保留解除入口。

## 成本与通知

采购倍率记录同一来源自身的相对变化。跨账号比较还需要在“供应商与成本”中确认共同计价基础，并为模型录入输入、输出、缓存读写、币种、token 单位、换算和有效期。系统按最近非合成 usage 结构及充值比例折算 USD/百万 tokens；任一项未知就显示不可比较。质量规则不改用户售价；分组倍率公式单独保存或手动应用。

余额续航需要同来源、同单位的至少四个余额点和十五分钟跨度。充值、额度重置、单位变化、数据过期或消耗波动过大都会停止预测。续航预警只提醒补充余额或准备备用。

通知支持通用 JSON Webhook 和企业微信。通用消息包含 `event_id`，接收端应去重。投递失败最多尝试五次；HTTP 成功但回执保存失败时可能重复投递，不能假设严格 exactly-once。

## 运维判断

“最近一次探测成功”不等于全部质量正常。检查质量页的风险、原生资格、供应商独立性、容量可信度、证据年龄、接管状态和写回错误。来源、凭据或映射更换后，旧代次证据自动退出控制；新证据不足时保持 unknown。

进入生产前验证真实请求、流式输出、工具调用、会话绑定和实际路由分布。多个账号也可能来自同一供应商，健康账号数量不代表独立容量。

## 换源和控制事件

更换地址、密钥、模型映射或计费来源后，质量页会等待新来源证据。历史记录仍可查看，旧零余额和旧探测不参与新来源的控制。升级数据库后也需要重新采集，不能用旧缓存判断已经恢复。

“原生候选：资格未知”表示目标接口没有提供足够的运行约束，或当前账号类型尚未适配。该账号可以继续由 Sub2API 调度，但 Pilot 不把它认证为暂停其他账号所依赖的备用。原生额度耗尽的周期即使看起来已到重置时间，也要等待新读回确认。

“事件与通知”分开展示主动探测、真实请求、余额、采购倍率和控制写回问题。供应商质量正常时仍可能存在管理接口故障。控制失败查看页面原因与动作历史；超过五分钟的待确认控制有独立事件。修复权限或网络后重试评估，控制器会核对旧动作，确认或撤销未执行部分，恢复通知只发送一次。不要为了清除提示而直接修改本地所有权记录。

## 分组入口、任务与效果

“服务探测档案”使用固定合成提示。分组档案经过用户入口；账号档案从 Pilot 网络直接访问供应商，不应用 Sub2API 的代理或模型映射，两种结果不能混算。流式首内容、完整结束和工具 JSON 结构分别验证，工具不会执行。请求发送后不自动重试；每日请求、token 及可选金额预留在发送前事务扣减。

真实请求按站点代次、group_id 和 request_id 合并。同一请求的重试错误与最终成功只算一个结果；没有最终标志、流结束信息或稳定 request_id 时显示未知。`/ops/requests` 的总耗时不会冒充首内容时间。

“动作与效果”比较同一档案代次的前后窗口。样本不足、未确认请求、来源/档案变化和人工修改都显示效果未验证。恢复使用“还原人工基准并停止”，只处理仍由 Pilot 管理且当前值匹配的字段；调度开关单独管理。

“运行状态”显示站点采集、任务租约、积压、最近执行、数据库连接和进程负载。出现采集失败时先处理读取权限或接口兼容，再判断供应商质量。


## 分组最终结果与采集盲区

运行状态页将请求明细、上游尝试错误和最终请求错误分别列出。每类接口使用同一 15 分钟窗口，最多三页、每页 100 条。供应商样本以成功记录和上游尝试错误为基础；同一次失败不会再加上最终错误重复计数。

最终请求按分组与请求标识去重。上游 503 后备用成功只降低该上游的质量；最终错误接口确认的 429 会计入分组失败。流式记录没有明确结束字段时显示未确认，不把总耗时当首字。接口缺失、无权限或截断时保留失败事实，但不使用不完整成功样本认证健康。

“上游采购声明覆盖”读取 Sub2API 已有状态，区分有效、过期、未启用、不支持和失败。有效声明不代表余额经过独立核实，也不替代供应商价格卡、币种和充值换算。查看此处不会启动采购探测或更改用户售价。
